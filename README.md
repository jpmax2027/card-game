Crown Duel — a turn-based card battler for the throne. You, the Challenger, face King Roderick with a 20-card deck: strike, guard, heal and special cards, 3 energy a turn, 30 life each. Playable offline in a desktop browser from its own files, with mouse and keyboard, a greedy AI rival, animated duels, and win and loss screens.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
